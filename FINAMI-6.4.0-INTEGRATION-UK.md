# Finami 6.4.0 — Design 3.0 Integration Preview · Build 48

База: Build 47 (архів не змінено). Це інтеграційна збірка вихідного коду, а не підтверджений реліз iOS.

## Додано
- Design Lab: вибір стилів розстрочок, найближчих платежів, підписок, календаря, редактора операцій та звітів; розміри й незалежні збережені параметри; вибір діаграм тільки для відповідного виду даних.
- Розстрочки: Payment Timeline та Timeline Progress Pro, фактична частка сплаченої суми, кільце, імпортовані поділки графіка (за наявності даних; максимум 24), наступний платіж і прострочення; збережено індивідуальне згортання та наявні дії. Поділки без підтвердженого запису не видаються за оплачені.
- Найближчі платежі: Original, Payment Timeline, Payment Focus, Banking Pro; ліміт кількості, налаштування показників та S/M/L, окремі підсумки UAH/USD, наявне згортання блока. Для Original з незмінними налаштуваннями зберігається попередня картка. У спрощеній головній нові стилі застосовуються при явному виборі.
- Підписки: Original, Compact List, Premium Cards, Billing Cycle, Subscription Pro; іконки сервісів на основі локальних символів, наявні фото, власні іконки та колір, фільтр стану, індивідуальна маска суми й згортання; оцінки з урахуванням періодичності. Це не офіційні завантажені логотипи брендів.
- Календар: Original, Calendar Pro, Agenda Timeline, Cash Flow, Heatmap. Фільтри типу, стану, рахунку (лише відомий рахунок фактичної оплати), згортання списку, підсумки/прогрес у межах валют. Майбутнім платежам не приписується невідомий рахунок.
- Редактор: Original, Quick Entry, Banking Pro, Minimal, Smart Entry. Спільна форма і наявна перевірка збереження. Системна клавіатура та один Finami Keyboard, вібровідгук, десятковий калькулятор, обрані/нещодавні категорії, останній рахунок, повтор ручної операції, додаткові параметри, підтвердження. Повтор готує чернетку, а не створює транзакцію автоматично.
- Звіти: Original, Finance Pro, Analytics Bento, Minimal Reports, Smart Insights, Banking Premium. Індивідуальний стиль, розмір, порядок, приховування, перехід до операцій категорії. Donut, Bar Chart, Area Chart, Horizontal Bars, Treemap (slice-and-dice), Heatmap, Income vs Expense, Cash Flow Waterfall. Area Chart показує динаміку витрат, не історичний баланс; при від’ємних чистих категоріях замість часток — стовпчики. Збережено наявні звіти в гривні за курсом запису.
- Fusion Crystal №35 — без змін від Build 47. Окремих стилів клавіатури немає.

## Відмінності від повної специфікації та обмеження
- Це перша наскрізна реалізація груп стилів, не піксельно ідентичне відтворення всіх інтерактивних макетів. Частина оформлень використовує спільні компоненти та відрізняється акцентами, відступами й додатковими показниками. Не всі стилі/розміри застосовані до кожної альтернативної картки на головній.
- Повні офіційні логотипи банків/сервісів, усі незалежні перемикачі для кожного блока, повний рідновалютний звіт, графік історичного балансу, усі запропоновані інтеракції безпосередньо на діаграмах та візуальна перевірка ще не завершені. У календарі рахунок майбутньої оплати не зберігається у чинній моделі, тому такий платіж має стан «Не визначено». Фільтри календаря та підписок є станом поточного екрана, не всі фільтри зберігаються після перезапуску.
- Приховування нових аналітичних графіків та сум перевірено на рівні політик і шляхів виведення, але візуальні/UI перевірки потрібні на iPhone. Редактори можуть показувати значення для свідомого редагування.
- Не змінено модулі фінансових розрахунків, імпорту, автоматизації та резервного копіювання. Редактор використовує попередній шлях валідації й збереження; додані лише підготовка чернетки, підтвердження та збереження параметрів оформлення.
- Два стилі операцій, назви яких не відновлено, залишаються Merchant Cards і Daily Journal (Preview) із Build 47.
- Linux не має Xcode/SwiftUI SDK, тож синтаксичний розбір Swift не є компіляцією застосунку. UI-тести, шифрування macOS та встановлення на iPhone не виконано.

## Встановлення і перевірка
1. Збережи резервну копію бази в поточній версії Finami. Розпакуй Build 48 в окрему папку, не перезаписуй Build 47.
2. На macOS у папці проєкту: `xcodegen generate`; відкрий `Finora.xcodeproj`, перевір signing, виконай Build та Run на симуляторі/пристрої.
3. Ще → Design Lab 3.0 → Компоненти: перемикай стилі, перевір кожний розмір та перезапуск. Діаграми вмикаються в Design Lab; вибір діаграм розділений за типом даних. У звітах через повзунки відкриваються параметри кожного блока.
4. Перевір контрольні суми з Build 47 на копії тієї самої бази: власні перекази, повернення, кредити, UAH/USD, часткові платежі. Окремо перевір приватність, приховані підписки, груповані й пов'язані операції, калькулятор, прострочення, від'ємні категорії, порожні дані та нульові суми.
5. `bash Tests/run-regression.sh` — локальні перевірки; Xcode і наявні GitHub Actions — компіляція та UI. Новий тест `Tests/check-design3-integration.sh` охоплює незалежність нових налаштувань, сумісність типів діаграм, періодичність, приватність прогресу та калькулятор.
