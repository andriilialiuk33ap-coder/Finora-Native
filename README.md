# Finora Native 3.0 — iPhone / Windows

Нативний SwiftUI-проєкт для iOS 16+. Не потребує Scriptable, браузера або сервера під час користування. Без зовнішніх API. Дані локальні. Це вихідний код, а не вже скомпільований IPA: синтаксис Swift перевірено, збірку Xcode та запуск на iPhone ще не перевірено.

## 1. Зібрати програму без Mac

1. На Windows завантаж і розпакуй ZIP. Встанови GitHub Desktop з https://desktop.github.com/ та створи безкоштовний обліковий запис GitHub.
2. GitHub Desktop → File → Add Local Repository → Choose. Вибери розпаковану папку Finora-Native (у ній є project.yml, Finora, .github). Якщо програма пропонує створити репозиторій тут, погодься. Переконайся, що в корені репозиторію є project.yml та .github/workflows/build.yml. Якщо потрібен коміт, натисни Commit to main.
3. Натисни Publish repository. Для безкоштовного стандартного macOS runner зніми Keep this code private (Public). Назва: finora-native. Не завантажуй жодних фінансових записів, резервних копій чи ключів. Код стане публічним, твої фінанси — ні. Не додавай платіжну картку та не підключай платні runners.
4. Відкрий Repository → View on GitHub. Перейди в Actions → Build Finora IPA → Run workflow → Run workflow (main). Якщо workflow не видно, перевір наявність .github/workflows/build.yml у репозиторії.
5. Після успішної збірки відкрий її сторінку, у секції Artifacts завантаж Finora-IPA. Розпакуй завантажений архів: у ньому буде Finora.ipa. Якщо збірка червона, скопіюй помилку з кроку Build unsigned iPhone application. IPA не підписаний, далі підпише AltStore.

## 2. Встановити AltStore Classic

Офіційна інструкція: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
1. Встанови iTunes та iCloud за посиланнями з офіційної інструкції (не з Microsoft Store, якщо не використовуєш описаний у ній обхідний варіант).
2. Завантаж AltServer для Windows з https://altstore.io/ (Classic, не PAL). Розпакуй AltInstaller.zip, запусти Setup.exe, після встановлення — AltServer від адміністратора.
3. Підключи розблокований iPhone кабелем. Натисни «Довіряти». У iTunes увімкни синхронізацію через Wi-Fi.
4. У системному треї Windows вибери AltServer → Install AltStore → твій iPhone. Використай безкоштовний Apple Account. Пароль не надсилай у чат або GitHub.
5. На iPhone довіряй власному профілю: Налаштування → Загальні → VPN і керування пристроєм. За потреби увімкни режим розробника (Приватність і безпека → Режим розробника), перезавантаж і підтвердь.
6. Передай Finora.ipa на iPhone (наприклад через iCloud Drive або інший приватний спосіб). В AltStore → My Apps → + вибери IPA у «Файлах». AltServer має працювати, iPhone має бути підключений або в тій самій Wi-Fi мережі.
7. Запусти Finora з головного екрана. Створи кілька тестових операцій, перевір звіти, резервну копію та відновлення, перш ніж переносити реальні дані.

## 3. Поновлювати підпис

Раз на 7 днів (краще на 5–6 день) запускай AltServer на ноутбуці, з'єднай пристрої кабелем або однією Wi-Fi мережею та натисни AltStore → My Apps → Refresh All. Не видаляй Finora для поновлення; видалення знищить її локальні дані. Якщо підпис прострочено, віднови підпис, не видаляючи програму. Регулярно експортуй JSON у приватну папку «Файли». Інтернет потрібен для збірки та підпису, а не для ведення фінансів.

## Можливості вихідного коду

- Нативні вкладки, системна світла/темна тема, Swift Charts (річні доходи та витрати).
- Витрати, доходи, перекази, пошук, редагування й видалення.
- Рахунки в UAH, початкові залишки, від’ємні кредитні баланси. Суми зберігаються цілими копійками.
- Загальний бюджет і ліміти категорій, власні категорії.
- Борги, цілі, розстрочки, регулярні платежі (ручне підтвердження), календар, локальні нагадування.
- Локальний статистичний помічник (без генеративного ШІ), прогноз місячних витрат.
- Face ID / код-пароль, JSON-резервування, CSV-експорт, імпорт доходів/витрат і загального бюджету зі старої JSON бази.

Ще не реалізовані: імпорт PDF/XLSX/CSV виписок, сканер чеків, прямі банківські API, автоматизації SMS/Apple Pay, віджети, мультивалютні рахунки, автоматичне перенесення старих боргів/рахунків/цілей та генеративний ШІ. Після внесення платежів за боргами перевіряй записи: відображення як доходу або витрати опціональне і не є повноцінним бухгалтерським обліком.

## Структура
- Finora/Finora.swift — вихідний SwiftUI-код.
- Finora/Assets.xcassets — іконка.
- project.yml — конфігурація XcodeGen.
- .github/workflows/build.yml — збірка IPA без цифрового підпису.
