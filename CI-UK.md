# Finami 5.1.3 — автоматизовані перевірки

Build 28. SHA і номер версії записуються у toolchain.txt. Регресійний набір включає нові перевірки платежів, повторного імпорту, пошуку, сумісності та налаштувань. XCUITest включає запис платежу з обраної картки і вимірювання запуску.

1. Розпакуйте архів у локальний клон Finora-Native (не видаляйте .git).
2. Commit + Push у GitHub Desktop. Тести запускатимуться при зміні вихідних файлів і тестів.
3. Для ручного запуску: Actions → Test Finami on iOS Simulator → Run workflow. Прапорець build_ipa за замовчуванням увімкнений, IPA створиться лише після успішних перевірок.
4. У результаті відкрийте Artifacts: Finami-Simulator-Results (навіть при помилці), Finami-IPA-Tested (якщо увімкнено збірку та всі тести пройшли).
5. Якщо є помилка, надішліть ZIP Finami-Simulator-Results. Він містить журнали, скриншоти та xcresult, якщо їх вдалося створити.

Перевірки симулятора використовують окрему тестову базу. OCR-тест використовує згенероване тестове зображення, не ваші особисті фотографії. Apple Pay, справжні банківські push та поведінка під замком потребують фізичного iPhone. Налаштування workflow не є підтвердженням його успішного виконання.

Оригінальний Build Finami IPA залишається доступним окремо і не запускає XCUITest. Переважно користуйтеся тестовим workflow для перевіреної збірки. macOS jobs використовують квоту GitHub Actions.

Додано XCUITest testExistingOperationLinksToInstallment та регресійні перевірки прямої прив’язки платежу.


Для 5.3: `Tests/check-53.sh` включено в загальний прогін. Перевір також новий експорт та встановлення словника в інтерфейсі; фактичне збереження PDF/XLSX/ICS перевірити на iPhone.
