# Build 89 — Recovery preview (не реліз)

Зміни: окремий екран у Root після існуючої автентифікації, блокування маршрутів віджетів, діагностика першої помилки в циклі операцій (номер та ID), експорт оригінального JSON, ручний редактор JSON, імпорт виправленого локального JSON, перевірка перед підтвердженням, відновлення через наявний strict restore із карантином, локальні snapshots. Версію та номер збірки не змінено.

Обмеження: редактор сирого JSON, не формовий редактор транзакцій; немає дифу балансів чи гарантії збереження всіх операцій після ручного редагування. Дублікати ID, refund links та помилки інших сутностей не локалізовано до рядка. Валідація і редактор працюють на головному потоці; великі бази потребують профілювання. Експорт оригіналу не містить зовнішніх вкладень та sidecar. Конкурентний міжпроцесний доступ не вирішено. Номер Build 89 залишено для порівняння, не розповсюджувати як реліз.

Перевірено на Linux: Tests/check-load-database.sh (додано перевірку номера та ID операції), Tests/check-storage-recovery.sh, swiftc -frontend -parse змінених Swift-файлів. Тести перевіряють наявні механізми та діагностику, але не повний новий UI flow. Xcode/iOS SDK недоступні; потрібні CI та тест на пристрої. Реальна проблемна база не надана; 0,01 ₴ не відтворено.
