# Build 88 — Architecture Candidate

Накопичувальний пакет від Build 80 (6.4.32). Номер 88 відповідає цільовому пакету плану, а не сертифікації всіх етапів. Це кандидат для тестування; не підтверджений стабільний iOS-реліз.

## Реалізовано

| Напрям | Зміни |
|---|---|
| 81 OCR | Консервативні підписи для першого внеску, комісій, кількості оплат та дат; окремий сервіс Vision. Опційний історичний `FinamiBankContractSnapshot` не змінює залишок або кредитний ліміт, не створює списань. Довідкові дані можна не зберігати. Нульовий найближчий внесок не підміняє регулярний. |
| 82 Storage | Спільний атомарний дисковий commit, фоновий запис великих імпортів/масових змін, резервування одного запису, контроль ревізії, завершення розпочатого запису навіть після скасування екранної задачі. Снапшоти та зовнішні вкладення сумісні з Build 71. |
| 83 Performance | Фоновий глобальний пошук операцій, скасування та контроль ревізії і приватності. Точне форматування копійок. |
| 84 Intelligence | Захист парсингу монобанківських даних, ключів дат, переповнення при звірці та колонок XLSX; серіалізація фонової обробки черги. |
| 85 Design | Спільні константи геометрії Fusion Crystal та піктограм платежів, без зміни значень; врахування маски в підписках. |
| 86 Widgets | Опційна версія схеми спільного JSON, обмеження розміру, відмова від невідомої схеми; старий JSON без версії підтримується. |
| 87 Quality | Виділено Vision, CustomDashboard, Subscription та Reminder UI. Нові цільові регресії. Старі скрипти залишено. |
| 88 Candidate | Контроль сумісності попередніх сценаріїв, Xcode Release Gate залишається чинним. |

## Межі

- Профілі підписів OCR перевіряються синтетичним текстом, не є підтвердженими реальними банківськими макетами. Повний графік, що містить комісію, не активується автоматично, якщо не збігається із залишком. Перший внесок і комісії — історичні метадані, не самостійні проводки. Фактичне виявлення на iPhone потребує тесту Vision.
- Не виконано повний перехід на Storage Actor, фонові звичайні записи, ChangeSet, окремі ViewModel для всіх екранів, фоновий кеш мініатюр, повну уніфікацію дизайн-токенів, об'єднання всіх джерел дедуплікації, повну консолідацію shell-тестів у XCTest. Частина UI-оцінок залишається наближеною. App Group concurrency і системний графік оновлення віджетів потребують тесту Apple SDK.
- Не змінено bundle ID, App Group, формат зовнішніх фото, шифрування, Aurora Balance, п'ять плиток Fusion Crystal. Перед переходом зробити повну резервну копію; старі збірки можуть не зберегти нові метадані при повторному записі.
- Довгострокова перевірка продуктивності в Instruments, реальні банківські зразки, CryptoKit, збірка Xcode та UI-тести необхідні перед стабільним випуском.

## Запуск

`bash Tests/run-regression.sh` та workflow `Test Finami on iOS Simulator` з увімкненим створенням IPA лише після всіх тестів. Для цільових регресій: `bash Tests/check-architecture-progress.sh`, `bash Tests/check-storage-recovery.sh`. Не додавати реальні фінансові дані до CI-фікстур.
