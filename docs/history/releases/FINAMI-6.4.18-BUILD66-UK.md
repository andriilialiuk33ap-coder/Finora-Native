# Finami 6.4.18 — Build 66 · Xcode type-check hotfix

## Причина
Обидва журнали Build 65 (124548410040, симулятор; 124548289978, IPA) підтверджують версію 6.4.17/65. Регресії, включно з macOS CryptoKit, пройшли (848 рядків PASS в кожному). Збірка застосунку завершилась exit 65: `FinamiOperations.swift:439:19` (симулятор) та `:366:23` (IPA): compiler unable to type-check expression in reasonable time.

## Зміни
- Розділено `OpEditor` на окремі обчислювані SwiftUI-компоненти: заголовок, сума, рахунки, категорії, зарахування, платежі, додаткові параметри, калькулятор і модифікатори форми.
- Пошук початкової витрати, форматування її підпису та типізовані Binding для компенсації/режиму зарахування винесено з великого ViewBuilder. Збережено ліміт 100 кандидатів, вибір раніше прив'язаної операції та маскування сум.
- Стан редактора, фінансова валідація, збереження операції, зв'язки з платежами, назви елементів керування та accessibilityIdentifier збережено.
- Фінансове ядро, OCR, Brand Icons, Aurora Balance, Fusion Crystal, тести й workflows не змінено.
- Версія 6.4.18, build 66. Обидва архіви містять `.github/workflows`.

## Обмеження
Локальний Linux не містить SDK SwiftUI/iOS. Перевірка синтаксису й регресій не замінює компіляцію Xcode. Потрібен новий Run workflow Simulator для Build 66, а не повтор старого запуску.
