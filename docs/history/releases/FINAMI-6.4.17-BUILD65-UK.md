# Finami 6.4.17 · Build 65 — CoreGraphics Hotfix

Основа: фінальний Build 64. Журнал GitHub Actions 124542926228, Xcode 26.6 / Swift 6.3.3 / macOS 26.7.2: перший етап фінансових регресій завершується кодом 1 через недоступні властивості CGRect у FinamiScanCore.swift. До iOS-компіляції та UI-тестів не дійшло.

- Явний умовний імпорт CoreGraphics у FinamiScanCore.swift, FinamiOCRLayoutCore.swift та трьох тестових скриптах, які створюють CGRect.
- Розділення виразів геометричної відстані на проміжні CGFloat без зміни порогів або формул.
- Версія 6.4.17 / Build 65. Фінансова модель, ресурси Brand Icons, OCR-профілі, Aurora Balance та Fusion Crystal не змінені.

Повний локальний прогін фінального дерева: 846 рядків PASS, exit 0, включно з перевіркою синтаксису Swift. Окремий цільовий прогін: 64/64 (17 просторових OCR, 28 брендів/профілів, 9 навчання позицій, 10 графічних ресурсів). Цільові перевірки входять до загального набору, не додаються до його кількості. Linux Swift 6.2.1; CryptoKit/CommonCrypto пропущено. Підтвердження виправлення на macOS, компіляція Xcode, UI-тести та робота Vision на пристрої ще не виконані.

Patch призначений для оновлення Build 64, обидва архіви містять .github/workflows. Рекомендована резервна копія перед встановленням.
