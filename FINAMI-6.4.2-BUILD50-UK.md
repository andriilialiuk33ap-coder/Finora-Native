# Finami 6.4.2 · Build 50

Основа: Build 49. Виправлення переходу з головної картки «Потребують уточнення».

- Заголовок, лічильник/кнопка та згорнута картка відкривають наявний екран «Уточнення операцій».
- Список відповідає вибраному місяцю головної та показує лише записи `kind.needsReview`. Після збереження уточненого типу запис зникає зі списку; лічильник оновлюється при поверненні. Згортання/розгортання картки доступне через її контекстне меню.
- Збережено маскування сум на екрані списку, чинний редактор операцій, правила обліку та навігацію Fusion Crystal.
- Додано UI-тест з ізольованим QA-набором: два неуточнені записи за поточний місяць, один уточнений, один за попередній місяць; перевіряє список і відкриття редактора.

Локально: синтаксис 4 змінених Swift-файлів та 48 перевірок Design 3.0 пройдено. Xcode, новий UI-тест і повний регресійний набір Build 50 не запускалися. Потрібно підтвердити роботу через GitHub Actions.
